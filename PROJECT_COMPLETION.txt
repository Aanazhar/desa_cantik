🎓 ROUTES & API ENDPOINTS | RUTE & ENDPOINT API

Public Routes:
  GET /profil-desa
    → Display profile page with sections
    → Controller: HomeController@profile
    → View: profil-desa-tabbed.blade.php

Admin Routes (Protected by 'admin' middleware):
  GET /admin/desa-profile-sections
    → Display section management dashboard
    → Controller: DesaProfileSectionController@index
    → View: desa-profile-sections.blade.php

  PUT /admin/desa-profile-sections/{id}
    → Update section content & image
    → Controller: DesaProfileSectionController@update
    → Request: content, image

  PATCH /admin/desa-profile-sections/{id}/toggle
    → Toggle section active/inactive status
    → Controller: DesaProfileSectionController@toggleActive
    → Return: JSON response

  POST /admin/desa-profile-sections/reorder
    → Reorder sections (ready for UI implementation)
    → Controller: DesaProfileSectionController@reorder
    → Request: array of {id, order}
