COMMON ISSUES & FIXES

Problem: Admin menu tidak muncul
Fix: 
  - php artisan cache:clear
  - php artisan config:cache
  - Refresh browser (Ctrl+F5)

Problem: Tabel tidak exist
Fix:
  - php artisan migrate
  - php artisan migrate:fresh --seed (untuk dev)

Problem: Gambar tidak terupload
Fix:
  - Check public/uploads folder writable (chmod 755)
  - Check file size < 5MB
  - Check format: JPG, PNG, WebP, GIF only
  - Check Laravel storage permissions

Problem: Tab tidak responsive
Fix:
  - Clear browser cache
  - Check no CSS/JS conflict
  - Check browser console for errors

CUSTOMIZATION TIPS

Change section label:
- Edit app/Models/DesaProfileSection.php → getSectionLabel()

Change tab styling:
- Edit resources/views/profil-desa-tabbed.blade.php → <style>

Add new section type:
- Update enum di migration
- Update getAllSections()
- Update getSectionLabel()
- Add form field di admin view

Increase file upload limit:
- Edit DesaProfileSectionController → uploadImage()
- Change max file size validation
